# Fridgy mobile

The Expo application for Fridgy. It uses Expo Router, React Native, TypeScript, and pnpm.

## Requirements

- Node.js 22.13 or newer
- pnpm 10.6.5
- Expo Go or a local iOS/Android simulator

Native iOS builds require macOS and Xcode. Native Android builds require Android Studio and an Android SDK.

## Development

```bash
pnpm install
pnpm start
```

From the Expo terminal, choose Expo Go, iOS, Android, or web. You can also run `pnpm ios`, `pnpm android`, or `pnpm web` directly.

## Checks

```bash
pnpm typecheck
pnpm lint
```
